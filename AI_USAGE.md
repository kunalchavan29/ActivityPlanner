# AI Usage

AI tools were used as development assistants during the implementation of Activity Planner.

## Areas Where AI Was Used

- Discussing application architecture and design decisions.
- Exploring Swift and SwiftUI implementation approaches.
- Assisting with Open-Meteo API integration.
- Reviewing Swift Concurrency and state management.
- Helping develop activity scoring logic.
- Preparing unit tests and project documentation.

## Developer Responsibilities

AI-generated suggestions and code were reviewed and adapted to the project.

The developer remains responsible for:

- Understanding the implementation.
- Reviewing architectural decisions.
- Checking API models and data mapping.
- Building and running the application.
- Verifying application behaviour and tests.

AI was used as an assistant, not as a replacement for development decisions or verification.
